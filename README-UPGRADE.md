# ArzPulse — Market Terminal v10

This release keeps the dense/immersive visual design while fixing the first-view rendering and adding a bilingual UX.

## UI changes

- English is the default language.
- Persian can be toggled from the header; direction, number formatting and all visible UI labels switch with it.
- English UI uses Inter.
- Persian UI uses Vazirmatn.
- The original galaxy/pulse identity is retained and made interactive.
- Restored and expanded Market Status section.
- No critical external chart dependency: charts are SVG-rendered in the browser.
- Live ticker loops continuously using two measured groups.
- Asset icons are inline text/SVG-style marks and do not rely on remote image loading.
- First paint contains useful structure even if data is slow/unavailable.

## Data model

The UI normalizes common fields:
`last`, `lastPrice`, `latest`, `price`, `close`, `high`, `dayHigh`, `low`, `dayLow`, `volume`,
`bestBuy`, `bestSell`, `bid`, `ask`, `change`.

Global instruments are read from `latest.market`.
Local instruments are read from `latest.prices`.
18K gold and USD/USDT use the project-level `gold18K`, `goldChange`, `dollarPrice`/`usdtPrice` fields.

## Deployment

Keep the existing GitHub Pages layout (`docs/` as the published folder) and the existing data workflow / Cloudflare scheduler.

Replace the UI files in `docs/` and keep `docs/data/` generated by the workflow.

For Cloudflare:
- Cron: `*/5 * * * *`
- Secret: `GITHUB_TOKEN`
- The token needs permission to dispatch the repository workflow.
